# SIT305 Quiz App – Task 3.1

A multiple-choice Android quiz application built for SIT305 Mobile Application Development at Deakin University.

## Features
- Enter your name to start the quiz
- 5 multiple-choice questions about Android development
- Correct answer turns green, wrong answer turns red
- Buttons lock after submitting so you cannot change your answer
- Progress bar updates as you move through the quiz
- Final score screen at the end
- Name is kept when starting a new quiz
- Finish button closes the app completely

## How to Run
1. Clone or download this repository
2. Open the project in Android Studio
3. Run on an emulator or physical device (Android API 24 or higher)

## Built With
- Java
- Android Studio
- XML Layouts
